# P03 两规格有限核验计划

版本 verification-plan-1.0；2026-10-13，北京时间。用户授权核验成交归属、盘口、属性及执行规则，交付字段说明和有限试跑报告。

对象固定为 AK-47 | The Oligarch (Field-Tested) 与 M4A1-S | Printstream (Factory New)。行情和混合成交窗口固定为北京时间 2026-10-12 00:00 至 2026-10-13 00:00，左闭右开。当前报价另按来源更新时间记录，不当作窗口内历史盘口。

## 范围和预算

- 复用单日试跑器，每个规格最多 4 个历史请求页、请求间隔 2.5 秒、独立库 16 MiB。两者均不追加旧市场库。
- 额外核验只访问公开商品页、其直接使用的公开脚本、明确发现的只读接口、Steam 和 UU 官方规则页。额外 HTTP 请求最多 60 次，其中网页/UU 公开读取最多 50 次，SteamDT 字段补查最多 10 次；网页/UU 每个响应最多 8 MiB、原始响应合计最多 64 MiB，字段补查独立库最多 16 MiB。网页可能返回压缩内容，分别记录原始响应大小和落盘大小。
- 保存原始响应哈希、请求参数、采集时间、实际代码版本和核验依据。接口失败、登录、验证码、401/403/429 时停止该入口，不绕过访问限制。
- 未知代码保持 unknown；空值保持 null；来源没有总数时不宣称真实成交完整率。当前最低价、量额非空率、挂售比等均不直接解释为可执行深度。
- 不提交订单或修改账户，不建立长期队列、正式数据集或模型。

## 验收问题

| 项目 | 所需证据 | 不足时的处理 |
| --- | --- | --- |
| 成交归属 | 平台代码与名称的直接映射；该映射确实用于成交接口 | 保留来源代码，逐笔不进入 UU 执行标签 |
| 盘口 | UU 在售/求购的方向、价格、数量、时间与分页范围 | 仅记录展示价或来源快照，深度 unavailable |
| 属性 | float、模板、涂装编号、贴纸的字段及缺失语义；关联到具体记录 | 分开已知、空数组与缺失，不能默认无溢价 |
| 执行规则 | 官方交易保护、可卖、收货、结算、资金复用、撤销与费用证据 | 标明页面时效和业务范围；账户适用性待核验 |
| 试跑质量 | 原始哈希、24 小时桶、量额缺失、重复与分页终止原因 | 有限观测结果，不能推广为全市场覆盖 |

交付字段契约、规则核验说明和有限试跑报告。字段准入按 L0 价格观察、L1 模拟执行、L2 实际执行分别判断；仅在必要证据满足时升级用途。
