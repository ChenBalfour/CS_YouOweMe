# 迭代方向

第一代完成采集流程和版本基线；v0.2.0 完成工程分层与课程建模设计。以下是后续研究计划，不代表现有功能。

| 阶段 | 目标 | 完成条件 |
| --- | --- | --- |
| v0.1 数据采集基线 | 公开页采集、样本、文档、测试与版本管理 | 本版完成 |
| v0.2 工程组织与研究设计 | 模块化源码、分层数据、回归 / 分类 / 聚类设计 | 本版完成；模型尚未训练 |
| 官方接口与历史数据 | 核对币种、K 线列定义、时间戳和频率，扩展商品与日期范围 | 真实返回验证通过；数据口径可复现 |
| 数据管线 | 增量采集、去重、失败恢复、时间对齐和质量监控 | 历史批次可追溯；更新流程可验证 |
| 因子与建模 | 根据实际可得数据研究收益、波动、流动性和平台价差等候选因子 | 处理缺失、陈旧报价、费用和时间信息，避免数据泄漏 |
| 回测与评估 | 时间顺序验证、费用和可执行性假设、基准比较 | 样本外结果及限制明确 |
| 决策辅助系统 | 输入武器、磨损档位和版本，展示行情、风险与可解释建议 | 输出与来源可追溯，清楚区分观察、预测和建议 |

未来界面可以加入预算与持有周期，但具体模型、因子和系统方案要在数据质量核实后决定。现阶段不实现自动买卖。

具体标签、候选因子、算法与验收顺序见 [因子建模方案](FACTOR_MODELING.md)。下一项实际任务为少量官方历史接口实测，并核实可用历史日期范围。
