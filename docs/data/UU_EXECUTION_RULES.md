## 时间与成本记录要求

分别保留 `decision_at`、`purchase_filled_at`、`received_at`、`earliest_sell_at`、`sale_filled_at`、`settled_at`、`funds_reusable_at` 和 `withdrawn_at`。未取得的时点保持 null；最早可卖的估计必须注明依据和版本，且不能提前于实际状态允许时间。

交易账本区分购买支出、出售净入账、实际交易服务费、实际提现事件、其他已核验费用、库存和未结算余额。提现费情景不对平台内每轮复用机械计提；价差若已包含在成交价中，不再重复扣同一成本。

未售出、未结算和被撤销的记录不能算已实现收益；按原事件继续追踪，不能删除这些样本改善回测。当前缺少上述执行证据，本轮不构造净收益或退出标签。

## 429 与后续核验方式

本次只观察到 HTTP 429，具体限流范围、恢复时间和认证条件未知；初次请求未记录 Retry-After，不能推定服务器允许何时重试。证据清单保存了失败状态和来源主机，采集器在同一核验运行内持久阻止该主机的后续请求。

后续在正常可访问的页面/经允许的只读入口核对两个精确规格的首屏单件、求购限制与账户适用规则，优先取得可比属性和独立时间。若存在服务端重试提示，应遵守；不得通过新运行 ID、换 IP、伪造认证或重复请求绕过本次限制。正常登录也不能预先保证解决 429。

若后续仍无法取得单件盘口和现行资金规则，保持 L0 价格研究用途；L1 净收益与退出模拟继续待验收。此次有限核验到此停止，不自动安排重试或持续监控。
