# 七品日级特征与标签

版本 seven-daily-guide-1.0；2026-10-20。组件`seven-daily-samples-1.0`。本页解释从冻结清洗库生成的研究样本；当前数量和后续路线统一见[进展](../PROGRESS.md)。

## 打开和查看

在VS Code打开[seven_daily_samples.ipynb](../../scripts/notebooks/seven_daily_samples.ipynb)，选择Python3.11+内核，运行全部。默认`RUN_BUILD=False`，读取已经生成的版本，显示七品样本统计、最近时点、输入字段和标签状态。无须登录，不发送市场请求，不训练模型。

```powershell
python -B scripts/build_seven_samples.py status
python -B scripts/build_seven_samples.py build --clean-id seven_clean_20261019_v1
```

已有版本不会覆盖。需更新时先由用户在采集Notebook显式完成有限更新，再新建清洗版，最后把这里的`CLEAN_ID`改为新的清洗ID、`RUN_BUILD=True`构建新样本；不能改指针后就把旧样本当成新数据。默认清洗ID明确固定，不自动选择另一来源。

## 一条样本是什么意思

每个商品每天北京时间10:00一条样本。输入覆盖决策前28天的672个小时，最新输入是09:00–10:00完整小时；七日点目标是`t+168小时`之前最后一个完整小时的来源收盘，即`bucket=t+167小时`。

| 部分 | 含义 |
| --- | --- |
| 键和追溯 | 精确商品、两平台编号、决策时间、输入和目标时间、父清洗版本 |
| 价格特征 | 当前来源参考收盘，过去1/3/7/14日端点收益、均价偏离、只用相邻有效小时收益的波动及过去价格范围 |
| 缺失特征 | 过去有效覆盖、最长连续缺口、价格年龄等；NULL保持缺失，明确0和未知分开 |
| 同期其他品 | 同决策时点其他商品的过去7日端点收益中位数和可用成员数；排除自身，不按未来标签资格选成员 |
| 七日点标签 | 真实未来来源收盘及相对当前参考价的收益；只在未来成熟、目标小时真实有效时提供 |
| 七日路径风险 | 未来168小时真实完整时才计算的来源期间高低/风险信息；路径中途缺口不伪造 |
| 准入与状态 | 完整输入、95%覆盖且最近24h完整、点/路径标签可用、时间分组和标签隔离分别记录 |

完整预测输入列以冻结产物的`feature_fields`为准。模型只能显式选这些列；`y_`、未来可用状态、样本准入、来源修订编号和最终报告截止均不能自动加入输入。缺失类型中依赖后续观察的信息不作特征。来源量/额口径未完全核验，第一版不作为预测输入；普通属性和UU盘口未接入此样本。

原始参考/目标价格保留精确文本和对应小时链接；计算用的收益、均值和波动为浮点研究特征，不回写来源价格。保留真实暴涨暴跌，不截尾、不平滑、不按当前百元价格带删掉历史行情。

### 21个输入的具体口径

收益和比例使用小数，例如0.05表示5%；所有窗口都在决策前结束。

| 字段组 | 计算口径 |
| --- | --- |
| x_reference_close | 决策前最后完整小时来源收盘，单位CNY；无该小时就为空 |
| x_return_1d/3d/7d/14d | 参考收盘÷准确滞后端点收盘−1；端点缺失不找近邻替代 |
| x_ma_ratio_7d/14d/28d | 参考收盘÷窗口内真实有效收盘均值−1；只对观察值求均值，缺失信息另存 |
| x_vol_7d/14d | 相邻真实小时对数收益的样本标准差，ddof=1，不年化；少于2对为空，不跨缺口 |
| x_adjacent_return_coverage_7d/14d | 真实相邻有效收益对数÷窗口预期对数（24×天数−1） |
| x_range_7d | 过去7天已观测最高价÷已观测最低价−1 |
| x_min_hourly_return_7d / x_max_hourly_return_7d | 过去7天相邻真实小时简单收益的最小/最大值 |
| x_price_coverage_28d/24h | 对应窗口有效价格小时数÷672或24 |
| x_longest_missing_hours_28d | 过去672小时内连续无有效价格的最长小时数 |
| x_price_age_hours | 距过去窗口最近有效小时的距离，最新有效为0；整个窗口没有有效价则为空 |
| x_peer_median_return_7d / x_peer_count_7d | 同日其他品可用7日收益中位数/成员数；没有成员时中位数为空、数量明确为0 |

路径高低收益相对于决策参考价，**不是最大回撤，也不代表CD内能按该价卖出**。标签始终是来源研究目标。

## 缺失与标签分开判断

例如七日后目标小时有真实价格，但第三天缺一小时：点价标签可以保留，完整路径风险标签仍为缺失。七日尚未过去时标记待成熟，不能补0或借后面最近一条价格替代目标。当前参考小时无有效价格也不借未来补输入。

同时保留严格完整输入与容缺输入对照。容缺门槛仍是预设的过去28天覆盖≥95%、最近24小时完整；它不是已验证的最优阈值。个别精确滞后端点缺失时，对应收益仍可为NULL，下游需要明确支持缺失的处理；准入标记不意味着任意估计器都能直接拟合，更不等于正式训练批准。

## 时间边界与使用限制

七品使用同日期分组：2026-04-01 10:00前训练段，之后到2026-07-01 10:00前验证段，再之后为探索测试段；前一组的七日标签到达下一组分界即隔离，不随机打散。所有品同日同组，不能一个品当天在训练、另一个品当天在测试。

旧测试期已经查看，仅供探索对照。新模型仍需滚动时间验证和未查看过的新前向数据；本次不拟合参数、不选模型、不重新评分旧测试。历史数据可能包含后来修订，`historical_available_at_verified=false`，不能宣称严格还原当时可见信息。

目标是SteamDT显式UU来源参考价，不是自己的UU可卖价或实际净利润。当前匹配报价、费用、收货/实际解锁/成交/结算另需接入；七日锁定期间不能假设提前出售止损。

## 输出与版本

`data/local/datasets/seven_daily/具体ID/`保存`samples.sqlite`、分开的`features.csv`/`labels.csv`、质量报告、字段/规范、准确代码依赖和父清洗manifest。`latest.json`只指具体成功版本，不覆盖历史版本。

父清洗版输出哈希先验收，通过SQLite `mode=ro`读取；构建后再次核对父输入不变。身份/时间结构错误、父版本不完整或篡改时停止；输出存在不覆盖，失败版本不成为latest。源库、清洗库、旧单品样本、预测评估和用户Notebook输出均不改写。
