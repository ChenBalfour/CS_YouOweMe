# 产品说明

版本 **product-1.15**；2026-10-20（北京时间）。本页定义目标、范围、用户体验和验收；实现见[产品架构](ARCHITECTURE.md)，实际成果、卡点与未来工作见[当前进展](PROGRESS.md)。

## 产品目标

构建面向悠悠有品（UU）的CS2普通枪皮研究demo：根据决策时点已经取得的历史信息，预测约七日后的参考价格与风险，再结合今天的匹配买价、未来可实现退出情景、费用和实际CD，判断是否值得买入。

核心问题是：**预计解锁后出售净入账，能否覆盖今天的购买总支出及成本，亏损风险与退出等待是否可接受？** 研究结果须可复核；没有发现有效预测信号，也是有效结论。价格预测本身不代表盈利或可执行卖价。

## 范围与交易策略

| 项目 | 约定 |
| --- | --- |
| 执行平台 | UU；SteamDT为主要研究来源，其他平台只作辅助 |
| 初始价格带 | 记录时间明确的UU普通在售价 `100 ≤ 价格 < 1000元` |
| 商品单元 | 普通枪皮＋精确标准磨损；不同磨损独立。当前先研究7个候选，不保证价格永久处于该范围 |
| 初版排除 | StatTrak、纪念品、刀、手套和依赖特殊属性溢价的规格 |
| 属性 | 在售与求购必须匹配float/模板/贴纸等条件；没有字段或页面没显示标签不证明无条件 |
| 退出 | 七日CD实际解锁后尽快尝试出售；买入、收货、解锁、成交、结算分别记录 |
| 使用方式 | 用户在本地VS Code运行Notebook，查看结果后自行操作 |

用户已确认普通次时代崭新按标准磨损研究，暂不把细磨损和少量普通贴纸作为独立预测特征；显著特殊溢价挂牌另标。这是该单品的demo假设，不推广为其他六品或任何未来求购永久无条件。选品依据见[规则](research/SELECTION_REVISION_20261014.md)。

`+168小时`来源收盘是初版研究目标。真正何时能卖依据收货、保护期及平台可卖状态；CD内不能假设提前止损。解锁后未售出、等待和未结算同样保留，不能只统计成功交易。

## 数据与预测思路

SteamDT显式YOUPIN小时OHLC为主要研究输入；来源量额保留原口径与未知项，不能直接称UU实际逐笔成交。4小时/日/周从小时聚合并保留完整性。UU历史价格与在售数量提供对照/供给信息，当前匹配在售、求购、数量与费用支持执行判断。BUFF尚未接入主流程。

数据保留真实时间与频率，不制造波动、不用未来插值填过去。缺失用NULL、mask、信息年龄和质量指标表达；非法字段隔离留据，真实暴涨暴跌保留。价格/量额诊断不直接认定操盘或情绪。缺失策略与近期一手方法见[清洗字段](data/STEAMDT_CLEANING.md)、[方法调研](research/DATA_METHODS_20261019.md)。

训练与推断都要遵守当时可得信息：事件时间、来源更新时间、采集时间及可得时间分开；后来下载/修订的历史值不能无证据视为当时已知。不同来源按已核验身份/指标和过去已知时刻对齐，不按行号拼接或平均。详见[来源对齐设计](data/SOURCE_ALIGNMENT_PLAN.md)。

日常采用**每日固定时刻推断、买入前刷新UU匹配报价**；小时采集/留存频率按运行预算逐步验收，每周另作较深历史复核。当天决策前已经取得的信息当天可用；当天尚未结束的日K、后续高低价不可用。每周才更新一次不能提供每日新鲜趋势。

逐品历史价格与UU当前快照均落盘，Notebook负责计算和展示。明天的K线无法还原今天的价差、属性、数量和采集时刻；当前快照既支持决策，也能积累为将来合法的历史特征。

## 模型与验证要求

先冻结样本/标签规范，再做特征工程和模型对照。七日终点价格与期间路径风险是不同目标，分别标记可用性；未来不足不补标签。多品按同日期划分，使用标签隔离和滚动时间验证；预处理/拟合只用训练段，选择只用验证段。

固定持平作为底线，再比较简单统计/小模型及适合的预训练时序或表格模型。深度学习不保证更准；单品数百个高度重叠样本不足以证明复杂模型可靠。已查看的测试集不得反复用于调参后仍称独立测试，需要新前向留出。误差、极端行情表现和区间覆盖同时报告，不能将七日重叠样本当独立交易。

当前已实现七品采集、清洗及[21特征/独立七日标签](data/SEVEN_DAILY_SAMPLES.md)，另保留旧单品严格样本和固定规则图表。**七品新样本尚未接入新模型评估，没有拟合模型；初次单品趋势规则未超过持平。** 历史可得时间与UU执行收益未验收。具体分数和下一步只在[进展](PROGRESS.md)维护。

## 用户流程与输出

1. 更新并检查商品身份、数据截止、缺口、新鲜度和访问状态。
2. 显式选择冻结数据、特征、模型和规则版本，运行推断。
3. 在Notebook看到历史真实曲线、预测路径/区间、留出误差和未知项；未来真实行情未知时不画假曲线。
4. 刷新同规格同条件UU报价，计算费用与实际解锁退出情景，展示判断理由。
5. 若用户买入，记录收货、解锁、出售、等待和结算；后续每日更新风险判断。

完整demo建议采用“候选购买／观察／暂不购买／数据不足”。每条结果须包含精确规格、适用属性、决策/数据截止时间、七日参考价格及风险、匹配报价/数量/费用、实际CD、版本追溯和理由。费用未知不能当0，来源上涨不能直接变买入信号。每日有判断不等于每天必有买卖。
