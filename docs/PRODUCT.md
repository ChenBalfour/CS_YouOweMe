# 产品说明

版本 **product-1.13**；更新日期 **2026-10-19，北京时间**。

本页说明 CS_YouOweMe 要解决的问题、范围与验收标准。[产品架构](ARCHITECTURE.md)说明如何实现，[当前进展与卡点](PROGRESS.md)记录已完成成果和下一步。范围或策略变化时更新本页；每次操作完成后更新进展页，并按文件制度记录版本。

## 产品目标

构建面向悠悠有品（UU）的 CS2 普通枪皮研究 demo：根据决策时点已取得的信息，预测约一周后的价格与风险，评估实际解锁后能否按合理价格退出，输出有依据、可追溯的购买判断。

核心问题是：**预计解锁后的出售净入账，能否覆盖今天的购买总支出及相关成本，亏损风险与退出等待是否可接受？**

研究成功以数据口径可信、过程可复现、限制清楚为标准。盈利能力是待检验结果；模型没有发现有效信号，也可以是有效结论。

## 首批范围与策略

| 项目 | 约定 |
| --- | --- |
| 目标执行场所 | UU；其他平台作为辅助信息来源 |
| 价格范围 | 有来源和时间的 UU 普通在售价满足 `100 ≤ 价格 < 1000 元` |
| 商品范围 | 普通版枪皮；不同标准磨损分别作为独立规格 |
| 属性要求 | 优先同磨损档内属性差异较小、普通件易匹配通用求购的规格 |
| 排除范围 | StatTrak、纪念品、刀、手套及依赖特殊属性溢价的首批规格 |
| 退出策略 | 七日 CD 实际解锁后尽快尝试出售 |
| 操作方式 | 用户本地运行采集与研究入口，查看建议后自行决定 |

求购若限定 float、模板、贴纸等条件，只能和满足条件的在售商品比较。没有条件字段或页面未显示标签，均不能推定无条件。原初选名单仅供复核，当前百元名单尚未冻结，规则见[选品计划](research/SELECTION_PLAN.md)。

2026-10-19单品研究简化：用户确认普通USP消音版次时代崭新没有细磨损限制，接受以标准磨损档作为demo研究单元，暂不把细磨损或少量贴纸作为单独预测特征。明显依赖特殊属性溢价的挂牌另标，不把其溢价计入普通件执行报价。这是该单品初版价格研究假设，不要求继续补齐全部属性标签后才能研究；不推广为所有求购永久无条件或贴纸一概无影响，也不自动修改其他六品或已冻结快照的执行状态。

约 `+168 小时`的来源价格可作为初版价格预测参考目标。执行退出则依据实际收到物品、交易保护和最早可卖状态确定；购买、收货、解锁、出售成交、结算和资金可复用是不同时间。

七日 CD 到期不保证立即成交。锁定期间可以评估风险，不能模拟提前卖出止损；到期未售出或未结算的样本必须保留，不能删除后只报告成功交易。

## 本地采集产品：当前已实现

SteamDT显式悠悠小时序列作为研究主输入候选，UU保留为供给、价格对照和执行平台。新增[VS Code有限采集入口](../scripts/notebooks/steamdt_research.ipynb)，由用户本地运行；集中维护精确商品名称、SteamDT/UU编号和历史起点。新商品按配置起点回补，旧商品续接未完成分页、增量补新并重查近期修订。数据库保留当前来源值、变化历史、原始响应与请求追溯；已停用商品不删除。

每个商品都展示实际首末时间、缺口和任务进度；“任务完成”不代表来源提供了全部历史。4小时、日和周视图从小时派生，量额缺失保留，较粗UU快照不制造细粒度波动。七个旧百元候选仍待属性与执行准入，不因能采到数据就进入正式买入名单。

日常至少每日更新近期研究信息，每周做较深历史复核，买入前另核对当前UU匹配报价。每周才更新一次数据库无法提供每日新鲜输入。未来每日进出按模型/成本/风险、实际可卖状态与成交条件判断，不能保证每天必有买卖。

## 离线基准与可视化

已增加[预测评估Notebook](../scripts/notebooks/cyrex_forecast_dashboard.ipynb)：比较事先固定的持平价与3/7/14日趋势规则，仅用验证集选择，再锁定查看测试集。每次保存独立评估版本，展示历史小时价格、七日规则路径、测试真实/预测对比及误差。研究起点和实际生成时刻分开，未来未知时不制造真实曲线或日内波动。

固定规则没有拟合参数，也未开始深度训练。初次验证选择持平，说明这几条趋势规则尚未优于简单基准；完整分数见进展。后续统计或深度模型须在同等边界下超过基准，并在新的前向留出段验证。不能看完当前测试反复调参后仍称独立测试；一个单品数百个重叠样本不保证复杂模型更准，应补更长时间、不同市场状态及可比多品序列。

逐品历史价格和当前UU决策快照都保存在本地；Notebook负责计算和展示。后来的K线不能还原当时价差、条件、数量及信息取得时刻。

## 用户流程与建议输出

1. 选择已核验的商品规格，查看数据时间、来源与质量。
2. 系统检查身份、可得时间、缺失、过期、属性匹配及当前能力等级。
3. 使用冻结版本的历史序列与当时可见快照进行模型推断。
4. 展示预测、不确定性、成本情景、退出条件及建议理由。
5. 若用户买入，后续按实际解锁状态评估退出，并记录等待与结果。

最终建议采用“候选购买／观察／暂不购买／数据不足”。候选购买须满足经验证的收益、风险与执行条件；缺少关键证据时降级为观察或数据不足，不能因为预测上涨就自动建议买入。

每条输出至少展示：

- 精确商品、版本、磨损与适用属性范围；决策时间、数据截止时间和来源。
- 预测参考时点、价格或收益区间、亏损风险及结果的不确定性。
- 已核验范围内的可匹配退出报价、数量与退出等待；未知项明确标注。
- 实际买价或明确的模拟买价、费用情景、预计净结果与建议理由。
- 名单、数据集、特征、标签、模型、成本与决策规则版本，便于复查。

界面中的价格预测与可实现出售价格分别展示。来源曲线、最高受限求购或辅助平台成交不能自动成为该件商品的退出价格。

## 每日决策与信息时间

设计采用 **每小时前向采集、每日固定时刻推断、准备买入前刷新匹配报价**。该频率是初版方案，尚未通过真实连续运行验收；具体输入窗口、聚合及决策时刻在正式数据集阶段冻结。

当天可以使用当天决策前已取得的信息，无须统一推迟一天。例如上午决策可使用昨日已发布的完整日线、过去序列和上午最新快照；当天收盘价、全天高低价和之后才发布的数据不能作为当天上午的输入。

训练也须重建当时的信息边界，分别记录事件时间、来源更新时间、信息可得时间和采集时间。当前下载的历史值不能无证据假定过去已发布，后来修订的数据也不能无声替换当时输入。

不同历史窗口保留真实时间点和频率。长期序列可在规则冻结后统一日粒度，近期小时信息另存；不能将每天两点的历史插值为真实小时数据。缺失与误差通过质量标记、适当降级和不确定性处理，不能填零后解释为市场没有交易。

当前已增加固定规则的离线探索评估与可视化，**没有拟合模型或开始深度训练**。截图核验后历史采集范围为成交价格7/30/90天/半年、在售数量7/15/30天，共7组；数量90天与半年在该页面未提供，保留缺口，不猜参数请求。新浏览器入口由用户在正常登录页面显式启动，44828一轮七组真实读取与离线入库已核验，多轮稳定性仍待验收。当前报价既支持当下成本/条件判断，也可积累为将来的历史特征；它不会被成交曲线完整替代。训练时缺少的盘口字段不临时加入推断，也不以今天盘口回填过去。

新增的操作体验目标是：用户首次在专用 Edge 正常登录并本地启动后，程序按指定商品清单自动跳转、选择图表、采集和保存入库；会话失效或验证时暂停交还用户。浏览器调度仍为待实现方案，现有七组采集入口仍需用户逐品操作。先验收单商品全流程，再验收有限多商品；不以新建 HTML 作为必须步骤。详见[浏览器自动采集方案](usage/UU_BROWSER_AUTOMATION.md)。

用户进一步优先要求采集时不打开网页，新增[本地纯脚本试用](usage/UU_DIRECT_COLLECT.md)：登录信息留在私有配置，先单请求、再有限队列，默认15秒请求/60秒商品间隔、并发1和滚动配额。本机当前配置已完成44828七组真实直连（1360条窗口记录、962个不同指标/时间点），不证明Cookie单独足够；多商品和多轮稳定性待验收；更换账号不解除访问停止，间隔不代表免封保证。浏览器方案作为后备，不代用户运行采集。

研究侧建议优先以SteamDT显式YOUPIN小时序列作主输入候选，UU补历史在售数量、价格对照和实际可匹配报价；交易执行目标仍为UU，七日CD规则保持。原始数据保留真实频率，第一版按每日固定时刻形成研究样本，小时/4小时方案后续比较。不制造缺失时段波动，不用未来插值；主序列覆盖、量额统计与历史可得时间仍先验收。详见[来源分工与时间对齐方案](data/SOURCE_ALIGNMENT_PLAN.md)，已有单品严格特征候选和七品清洗；清洗后的新预测特征与训练尚未实施。

| 来源或数据 | 产品用途与当前限制 |
| --- | --- |
| UU 历史图表 | 已取得用户导出及44828完整七组批次：1335条窗口记录、947个不同指标/时间点；基础质量与入库通过，完整身份、统计口径及历史可得时间仍待验收 |
| SteamDT 明确 UU 来源 | 已取得来源价格和汇总报价观察；逐字段确认归属，不等同单件盘口 |
| 来源量额与混合逐笔 | 仅保留原口径和未知项；未映射记录不能标作真实 UU 成交 |
| UU 前向快照 | 记录当时可见价格、条件、数量和时间，逐步补齐模拟退出证据 |
| BUFF、Steam 等 | 检验是否增加预测信息，分别映射规格与时间，不替代 UU 执行数据 |
| 订单、结算与规则 | 决定实际执行与资金账本；当前仍需补证 |

历史研究目标起点为 **2025-06-01，北京时间**，各来源能否覆盖尚待验证。历史研究集与前向观察集分别版本化；不存在的历史盘口、供给或条件不能用当前值或合成值回填。

历史在售数量表示挂牌供给观察，不等于成交量；成交价格不等于成交额。来源金额缺失时保留缺失标记，不能用“K 线价格 × 在售数量”还原真实成交金额。图表频率与字段线索详见[历史图表说明](data/UU_HISTORY_CHART.md)。

产品能力按证据分级：

| 等级 | 支持的产物 |
| --- | --- |
| L0 来源观察 | 来源价格变化、数据质量和研究候选提示；不声称能按该价成交 |
| L1 模拟执行 | 可比 UU 报价、时间和成交证据配合明确假设，估计净收益与退出能力 |

## 收益、风险与验证

购买判断同时考察价格变化、正净收益可能性、亏损风险和退出可行性。预测点价格只是其中一项；阈值、预算与仓位规则须在对应研究阶段冻结，不先承诺收益率或资金容量。

单件已完成往返的净收益按出售净入账、购买总支出和尚未计入的相关费用计算。买卖价差已反映在两侧价格中时不重复扣除；提现按实际资金退出事件记账，平台余额复用不机械地每轮扣提现费。实际费用与账户适用规则待核验，资金结算和机会成本分别报告。

先比较“不交易”、简单价格或流动性规则、普通统计模型，再判断复杂模型是否增加稳定价值。模型只定期重新训练，日常新数据用于更新输入和推断；训练频率由样本与验证结果决定。

按时间前推训练与评估，保留最终未参与调参的时间段。预处理只在训练窗口拟合，处理约七日标签跨窗口重叠和信息延迟；同日期、同涂装关联及回顾性选品偏差均须考虑。样本外表现、风险、成本敏感性与退出等待共同决定验收，不以一次回测上涨作为成功。
