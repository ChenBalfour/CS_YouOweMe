直接阻碍下一步的是 B01 登录页面连接/读取，以及 B03 历史指标、时间戳和统计口径核验。UU 界面已有图表，不把浏览器工具连接失败解释成网页没有数据；匿名入口429与登录后正常页面读取是不同问题。
