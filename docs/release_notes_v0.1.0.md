# CS_YouOweMe v0.1.0

第一代 CS2 饰品数据采集与挖掘研究基线，使用 Python 标准库。

- 公开详情页采集：商品信息、跨平台报价、关联规格。
- 20 条完整商品、180 条平台报价、267 条关联规格的可复现匿名样本。
- 原始 JSON、来源时间和 SHA-256，零值价格处理及陈旧数据标记。
- 本地 CSV/SQLite，官方 API 接口预留，离线测试和 CI。
- 空白配置模板、忽略真实密钥、提交与推送前检查。
- MIT 代码许可、字段字典及后续数据与建模计划。

当前没有历史日线、预测模型、因子、购买建议或交易执行。官方 API 真实认证与价格/K 线口径仍待验证。
