# v0.2.0 — 工程整理与课程建模设计

采集实现从单个根目录脚本拆入 `src/cs_youoweme/`；运行入口改为 `python scripts/collect.py`。源码、配置、数据、文档和测试按用途分开，公开样本与本地数据分别位于 `data/samples/` 和忽略的 `data/local/`，每批再区分原始资料、导出表和报告。

公开样本仍为 20 条商品、180 条报价和 267 条关联规格，原始 JSON 字节与 SHA-256 保持一致。真实密钥转存到本地 `config/.env`，公开模板为空；密钥检查、提交钩子和 CI 已同步新目录。

课程方案明确 Ridge 回归、逻辑回归和 KMeans 的用途，列出因子公式、时间隔离、基准评估与缺失数据限制。本版未训练模型，官方 API 的真实认证与历史字段核实仍待后续工作。

验证包含离线样本校验、CLI 从仓库外启动、配置优先级、保存页面的采集导出全流程、部分失败归档，以及提交文件与可达历史的密钥检查。路径迁移见仓库的 `docs/usage/COLLECTION.md`。
