## 0.2.0 — 2026-10-11

- 源码拆分为采集、解析、清洗、存储、配置与 CLI，命令入口改为 `scripts/collect.py`。
- 配置集中到 `config/`，本地密钥保留在忽略的 `config/.env`；兼容读取旧根目录 `.env`。
- 数据按公开样本 / 本地运行分开，每批区分 raw、tables、reports；更新样本追溯路径，原始 JSON 校验值保持一致。
- 文档分为使用、数据、研究、发布说明；完整初次试采项目保存在私有归档。
- 添加回归、分类、聚类研究设计与时间验证方法，明确单期快照及非成交数据限制。
- 更新 CI、Git 钩子与密钥检查路径，增加离线 CLI 全流程和配置优先级验证。
- 修复 SQLite 事务完成后连接未及时关闭的问题，避免 Windows 文件占用。
- 版本唯一来源迁入 Python 包，增加工程元数据。

命令与目录存在变更，迁移见 [采集指南](../usage/COLLECTION.md)。本版没有训练模型或新增真实 API 调用结果。
