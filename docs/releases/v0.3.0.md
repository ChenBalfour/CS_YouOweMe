# v0.3.0 — 千百战研究名单与历史数据库

新增可恢复的网页历史采集器和 SQLite 历史库，保留成交精确磨损、模板、贴纸、相位及来源 ID；小时行情保留来源量额和缺失值。支持分页事务、游标检查、去重、容量软上限与覆盖报告。

研究聚焦百元、千元价位的普通枪皮。筛选结合来源热度、低供给与活跃度，保留价格分层、同涂装上限、候补和排除理由。支持离线重建保存的观察，名单版本与成员可用 SQL 查询。旧成交任务迁移保留游标与检查点。

增加 VS Code 连接指南、工作区与只读 SQL；更新研究设计和迭代方向，清理重复文档及临时发现材料，保留来源审计与必要归档。

本地目录 44,502 个规格，早期试采 119,520 条小时行情、1,420 条成交。小时桶覆盖 2025-06-01 至 2026-10-11，逐笔成交未完整回填。第一版枪皮名单为 11 个规格，新名单历史回填尚未启动。真实密钥、数据库和完整审计名单留在本地，公开文档仅列核对过的初版选择摘要。

验证包括离线采集、分页恢复、事务、精度、容量、迁移、名单测试，本地真实数据库上的只读 SQL、密钥与历史检查，以及跨平台 CI。当前未训练模型或生成购买决策。
