# UU 指定商品浏览器自动采集方案

版本 **uu-browser-automation-plan-1.0**，2026-10-15，北京时间。状态：**设计已记录，浏览器调度程序尚未实现，未做真实页面自动操作验收**。

## 要实现的用户体验

用户在本地启动程序，首次在专用 Edge 窗口正常登录，确认商品清单；登录有效期间，程序依次打开商品、进入价格走势、选择成交价格与半年、完成七组采集、保存并离线入库。用户不再逐品打开页面、复制代码或挑选下载文件。登录过期、验证或访问限制需要用户处理，不承诺永久无人值守。

现有 collect_uu_charts.js 已完成单商品七组采集，import_uu_chart_batch.py 已完成离线入库；缺少的是浏览器操作、商品队列与自动交接文件。现有脚本仍是半自动入口，不能把本方案当作已经可运行的新脚本。

## 选择的实现路线

拟用 Python + Playwright 驱动本机已安装的 Edge。Playwright 支持 msedge 通道和独立的持久浏览器目录，可在用户完成正常登录后保留该专用窗口的状态；这不等于直接接管当前日常 Edge 的已登录窗口。[官方浏览器启动说明](https://playwright.dev/python/docs/api/class-browsertype)、[登录状态说明](https://playwright.dev/python/docs/auth)。

自动化操作真实 UU 页面，监听该页面正常产生的图表请求与响应，仍复用已验证的采集和离线校验能力。Playwright 提供页面网络事件与响应等待机制；实际 UU 菜单定位、会话表现和页面变化容错还需本地试跑验收。[官方网络说明](https://playwright.dev/python/docs/network)。

新建本地 HTML 可以作为任务面板，但单独打开的 file:// 或 localhost 页面不会自然获得 UU 页面的登录上下文，跨站读取也受浏览器规则约束。因此新增 HTML 不是实现自动采集的必要步骤；界面可以后做。

当前 Python 包仍无第三方运行依赖，本机检查未发现 Playwright。本次没有安装依赖、创建登录目录或启动浏览器。

## 调度流程与检查点

1. **用户启动与登录**：打开专用 Edge 配置目录，登录只由用户完成；不从日常浏览器复制 Cookie，不要求用户贴 Token，不把认证头写到日志、JSON、截图或源码快照。专用目录按凭证资产保护，不提交、不记录内容哈希。保护与忽略规则必须先于实际创建目录落实。
2. **加载有限队列**：每项包含 UU 商品链接、templateId、完整名称、磨损及普通/特殊版本；另存本轮清单版本、商品数、请求和时间预算。编号 44828 已有真实接口样例，完整商品身份仍未独立验收，不能直接当作正式百元候选。
3. **逐品导航**：串行打开真实商品页，核对页面规格和图表请求 templateId；菜单必须依据实际可见页面定位。身份不一致、控件不唯一或页面结构变化时停止，不能猜测点击或静默切到别的商品。
4. **自动选择与读取**：进入价格走势，选择成交价格和半年，依据正常成功请求确认该商品实际半年参数。随后完成价格7/30/90天/半年、数量7/15/30天，共七组。不能给数量添加90天/半年，也不能把所有时间序列当作固定采样。
5. **即时保存与入库**：每个任务落盘状态和成功原响应；单商品结束后交给既有离线校验器，生成独立 JSON、SQLite、CSV 和报告。导航失败也记录商品状态；已经完成的商品不覆盖。断电前尚未落盘的数据不声称可恢复。
6. **停止和恢复**：会话失效、401/403/429、验证、业务或结构异常均保存进展并停止队列，不自动反复刷新、重试或清除访问停止标记。用户正常访问恢复后显式继续，只处理未尝试任务；已有受限 Python 入口保持停止。

浏览器导航、页面初始化也可能产生额外正常请求，必须单独记账；不能把七个目标任务误写成整个浏览器仅有七次 HTTP 请求。并发保持1，沿用现有组间至少5秒及请求/响应限制，外层另设有限商品数、导航次数与整轮截止时间。

历史点 time、页面响应取得时间和本地保存时间分别保留；页面取得时间不回填为历史可得时间。自动化只减少操作，不改变成交价格统计未知、历史数量不等于成交量、历史曲线不等于即时可执行盘口等边界。

## 实现与验收顺序

| 阶段 | 交付与通过条件 |
| --- | --- |
| 单商品原型 | 用户完成首次登录并启动后，商品跳转、菜单选择、七组读取、落盘与入库均无需逐项操作；比对同商品手动结果 |
| 有限多商品 | 至少两个已确认规格按队列串行执行，响应不会串品，预算和各商品完成/失败/待采可查 |
| 中断与访问异常 | 人工中断、会话失效、菜单改变、访问受限的测试有证据；已保存结果保留，停止状态不能自动清除 |
| 多轮稳定性 | 用户在明确预算下进行多轮真实验证，检查覆盖、时效、历史修订和窗口重叠；达到验收后再安排日常更新频率 |

浏览器接口文档和离线模拟不能替代 UU 页面真实验收；当前只有既有手动入口的44828单轮七组成功证据。本方案不启动采集、后台定时、模型训练或交易。
